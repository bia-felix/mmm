# Graças Aventais: fichas ilustradas

Esta versão incorpora imagens fornecidas pela proprietária como referência visual e recortes clicáveis para modelo, gola, bolsos, punhos, manga e calça. Os controles ilustrados sincronizam com os campos do formulário existente.

## Atualizar no GitHub
Envie o conteúdo desta pasta para a raiz do repositório, preservando `templates/` e `static/modelos/`. Faça commit e execute Deploy latest commit no Render.

## Atenção
Apenas demonstração. O SQLite e os uploads em `/tmp` não são persistentes no Render gratuito. Não cadastrar dados reais de clientes. As imagens completas são referências, não substituem campos interativos.
